# CyberGuard – AI Based Safe Communication System

CyberGuard is an Artificial Intelligence based project designed to detect toxic and abusive communication in real time. The project focuses on creating a safer digital communication environment by identifying harmful text messages before they negatively affect users.

## Project Overview
Online communication platforms are growing rapidly, but cyberbullying, hate speech, and toxic conversations are also increasing. CyberGuard helps solve this problem using Machine Learning and Natural Language Processing techniques.

The system analyzes user messages and predicts whether the text is toxic or safe.
